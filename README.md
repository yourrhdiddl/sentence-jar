# Sentence Jar

웹페이지를 읽다가 마음에 드는 문장을 우클릭 한 번으로 모아 두는 크롬 확장 프로그램입니다.
모은 문장은 이 기기에만 저장되고, 바깥 서버로 보내지 않습니다.

## 할 수 있는 일

- 문장을 드래그한 뒤 우클릭 → **Save to Sentence Jar** 로 저장
- 아이콘 배지로 결과 확인: `OK` 저장됨, `Dup` 이미 있음, `!` 저장 실패
- 팝업에서 검색(찾은 단어 강조), 복사, 원문 페이지 열기
- 지운 뒤 5초 안에 **Undo** 로 되돌리기, 모두 지우기 전 확인 창
- 라이트 / 다크 모드 전환, 빈 화면 안내

## 설치 방법

1. 이 레포를 내려받습니다 (Code → Download ZIP 후 압축 풀기).
2. 크롬 주소창에 `chrome://extensions` 를 엽니다.
3. 오른쪽 위 **개발자 모드** 를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다** 를 누르고 이 폴더를 고릅니다.
5. 퍼즐 아이콘에서 Sentence Jar 를 **고정** 하면 저장 결과 배지가 보입니다.

## 파일 구성

| 파일 | 하는 일 |
|---|---|
| `manifest.json` | 이름, 버전, 권한(contextMenus, storage) 등 확장 프로그램 설정 |
| `background.js` | 우클릭 메뉴를 만들고, 고른 문장을 저장한 뒤 배지로 결과를 알림 |
| `popup.html` | 아이콘을 눌렀을 때 뜨는 팝업 화면과 디자인 |
| `_locales/` | 영어(en), 한국어(ko) 이름·짧은 설명·우클릭 메뉴 문구 |
| `popup.js` | 팝업의 목록, 검색, 복사, 지우기와 되돌리기, 테마 전환 동작 |
